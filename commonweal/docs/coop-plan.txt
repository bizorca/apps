The Cooperative Movement Angle Is a Feature Here                                
Framing volunteer supporters as "cooperative stewards" or similar — with        
recognition, skill-building, and community belonging as the compensation — is   
deeply on-brand. The people most likely to volunteer are people already         
embedded in the cooperative movement who want to grow it. You're giving them a  
structured way to do that.                                                      
This also creates a natural expertise ladder:                                   
                                                                                
New volunteers handle intake and information gathering

Expert volunteers (attorneys, accountants, CDFI officers) handle complex cases  
and final review                                                                
                                                                                
That ladder is also a retention and engagement mechanism.                       
                                                                                
What This Does to the MVP                                                       
It actually simplifies the client-facing MVP somewhat — you don't need to make

 the start, not retrofitted later.

     CoopConvert MVP — Vanilla PHP8 + Tailwind CSS

     Context

     A cooperative business conversion platform for Washington state small
     businesses. Helps retiring owners transition to worker co-ops,
     multi-stakeholder co-ops, and other cooperative structures under RCW 23.78.
      The app reduces the cost and friction of conversion (normally $5k–$15k in
     professional fees) via guided workflows, document generation, and financial
      modeling — supported by volunteer coordinators from the cooperative
     movement.

     Two-sided platform: business clients going through conversion + volunteer
     coordinators guiding them.
     Scope: Washington state only, MVP. No blockchain. No payment processing in
     MVP.
     Stack: Vanilla PHP8, PDO/MySQL, Tailwind CSS via CDN. Follow keel
     conventions exactly.

     ---
     Auth & Role System

     Three roles: client, coordinator, admin

     Helper functions in includes/config.php:
     - requireLogin() — redirect to login if not authenticated
     - isAdmin() — role = admin
     - isCoordinator() — role = coordinator
     - requireCoordinator() — redirect if not coordinator/admin
     - getCurrentUser() / getCurrentUserId() — standard session helpers
     - Standard: h(), url(), csrfField(), verifyCSRFToken(), setFlash(),
     getFlash()

     ---
     Feature Detail

     1. Structure Selector (structure-selector.php)

     Multi-step wizard (6–8 questions). Questions cover:
     - Who should own the business (workers, customers, community, mixed)
     - Number of potential members
     - Capital needs and financing situation
     - Owner's desired ongoing role
     - Governance preferences

     Scoring produces a ranked recommendation from:
     - Worker Cooperative (LLC-based or incorporated)
     - Multi-Stakeholder Cooperative (RCW 23.78 ULCA)
     - ESOP (employee stock ownership plan — flag as "requires specialist")
     - Consumer/Community Cooperative

     Result stored in structure_assessments. Display: recommended structure with
      plain-language explanation, legal basis (cite RCW 23.78 where applicable),
      pros/cons, and "have an attorney review" disclaimer.

     2. Deal Modeler (deal-modeler.php)

     Input fields:
     - Estimated business valuation
     - Seller note: amount, interest rate, term
     - CDFI loan: amount, interest rate, term (pre-populated with WA CDFI
     typical ranges: Craft3, Community Capital Development)
     - Number of members contributing

     Outputs (computed in includes/modeling.php):
     - Monthly payment to seller
     - Monthly CDFI payment
     - Total annual debt service
     - Per-member monthly contribution
     - Break-even analysis
     - Cash flow table (year 1–5)

     Saved to deal_models. Multiple scenarios per case allowed.

     3. Document Generator (documents.php)

     Templates for Washington state (hard-coded PHP template strings with
     variable substitution):
     - Worker Co-op LLC: Operating Agreement, Membership Agreement
     - ULCA Multi-Stakeholder: Articles of Organization, Bylaws, Membership
     Classes definition
     - Consumer Co-op: Articles of Incorporation, Bylaws

     Template variables populated from businesses and structure_assessments
     tables. Generated as HTML (printable/downloadable). Stored in documents
     table. Prominent disclaimer: "These are templates. Have a
     Washington-licensed cooperative attorney review before filing."

     4. Case Management (coordinator.php, case.php)

     Coordinator dashboard shows:
     - Queue of cases without assigned coordinator (claim button)
     - My active cases with status, last activity, business name
     - Status pipeline: intake → structure selection → modeling → documents →
     review → complete

     case.php shared view for coordinator + client:
     - Current status and next step prompt
     - Case notes thread (internal-only notes flagged for coordinator)
     - Links to all tools (structure selector, deal modeler, documents, equity
     ledger)
     - Coordinator can advance status, add notes, flag for expert review

     5. Equity Ledger (equity-ledger.php)

     Post-conversion tool. Add/edit member rows:
     - Name, email, equity class (Class A worker, Class B investor, etc.)
     - Capital account balance
     - Acquisition method (cash purchase, seller financing, sweat equity,
     patronage)
     - Acquisition date
     - Patronage basis (labor hours for period, purchase volume, etc.)

     Patronage dividend calculator: enter total distributable surplus → allocate
      proportionally by patronage basis → show per-member amount.

     ---
     Page Flow by User Type

     Client:
     1. Register → email verify → onboarding intake
     2. Intake (business details) creates a case
     3. Dashboard shows current stage + next action CTA
     4. Steps: Structure Selector → Deal Modeler → Documents → (coordinator

     Coordinator:
     1. Register as coordinator → admin approves (sets role)
     2. Coordinator dashboard → claim open case
     3. Case view: see client's progress, add notes, advance status
     4. Flag complex cases for expert review (admin)

     Admin:
     1. User management (approve coordinators, view all users)
     2. Case overview table (all cases, all statuses)
     3. System settings (placeholder for future config)

     - Washington small securities exemption (WAC 460-99C) crowdfunding module

     - Professional services directory
